# Sales Data Analysis Using Python

## Overview
This beginner-friendly project analyzes retail sales data using Python. It demonstrates data cleaning, exploratory data analysis (EDA), summary statistics, and visualization.

## Objectives
- Calculate total revenue, orders, and units sold.
- Identify top products by revenue and quantity.
- Compare sales across cities.
- Explore monthly sales trends.
- Visualize relationships between numerical variables.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Google Colab

## Files
- `archive.zip` — analysis notebook and graphs.
- `sales_data.csv` — dataset used in the analysis.

## How to Run
1. Download the notebook and CSV file from this repository.
2. Open the notebook in Google Colab.
3. Upload `sales_data.csv` to the Colab session if the notebook reads the file from disk.
4. Run the cells from top to bottom.
5. Review the printed metrics and graphs.

## Dataset
The dataset is simulated sample retail data created for learning purposes. It does not represent actual company transactions.
